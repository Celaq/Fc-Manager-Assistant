FC 온라인 감독모드 도우미 3.0.1 실행오류 수정 테스트 결과
검사일: 2026-10-06 (한국 시간)

수정 사항
1. 등급 변경 안내 팝업과 승급·강등·잔류 결과 화면의 확인 버튼 처리 추가.
   버튼 이미지뿐 아니라 팝업/결과 화면 구조도 함께 확인합니다.
2. 챔피언스 아래 등급의 승점 0/1/3은 랭킹 점수로 합산하지 않습니다.
   기존 랭킹 누적값을 무효화하고 등급 경기를 계속합니다.
3. 랭킹 점수 화면으로 복귀하면 다음 경기 전에 로비 현재점수를 두 번 읽어 재확인합니다.
   기존 누적값에 복귀 후 변화량만 더해 잘못된 총점을 만드는 동작을 제거했습니다.
   재확인이 실패하면 중지하며, 시작점수 읽기로 현재점수를 다시 확인해야 합니다.
4. -67점 숫자 표본을 보완했습니다. 기존 숫자 신뢰도 기준을 완화하지 않았습니다.
5. 점수는 최대 5회 판독하고 연속 2회 같은 점수/화면 종류가 확인되어야 반영합니다.
   끝까지 확인되지 않으면 점수를 추측하지 않고 다음 경기 전에 중지합니다.
6. 기존 Fixed 배포본의 창 전환 입력 방지, 재시작 전 시작점수 재확인,
   주차 조건 중지를 F8로 취소하지 못하게 하는 수정을 유지했습니다.

검증 결과
- 기존 3.0에서 핵심 재현 검사 4건 모두 실패 -> 수정본에서 모두 통과.
- 제공된 보상 화면 48장: 랭킹 변화량 31장 판독, 등급 승점 17장 합산 제외.
- 보상 화면 48장에서 기존 다음 버튼 유지, 새 등급 확인 버튼 오인식 없음.
- 강등 팝업 5장과 잔류 결과 화면 26장: 확인 버튼 31장 모두 인식.
- 목표점수 전 계속, 목표 도달 중지, 선택형 최저점수 중지, 승점 합산 제외,
  등급 복귀 시 실제 총점 재확인, 판독 실패 재시도와 안전 중지 검사 통과.
- Windows PowerShell 5.1: C# 판독기 컴파일, PowerShell 구문 검사,
  전체 Windows Forms UI 구성/대기 상태/종료 검사 통과.
- 총 144개 판독·동작 선택·상태 검사 통과. UI 구성 검사는 별도 통과.

검증 범위와 한계
- 저장 화면 재생과 상태 로직 검증입니다. 실제 게임에 키/마우스 입력을 보내지 않았습니다.
- 현재점수 재확인 흐름은 OCR 결과/캡처 어댑터를 대체한 상태 테스트입니다.
  실제 게임 로비에서 등급 복귀 후 OCR 및 마우스 진행은 별도 실게임 확인이 필요합니다.
- 승급 성공 화면 원본이 이번 자료에 없어 승급 성공 사례 자체는 미검증입니다.
  공통 등급 결과 확인 버튼 처리를 추가했으나 성공 화면에서 별도 확인해야 합니다.
- 원본 게임 창은 1296x759입니다. 다른 배율·해상도 실게임 검증은 미완료입니다.
- 백신 탐지 원인 수정/백신 통과 검증은 이번 작업 범위에 포함하지 않습니다.

사용 방법
1. 기존 프로그램을 종료하고 이 ZIP을 새 폴더에 압축 해제합니다.
2. Start_FC_Manager.cmd로 실행합니다.
3. 주차 모드는 챔피언스 로비에서 시작점수를 다시 읽고 목표점수를 설정합니다.
4. 강등 시 승점은 합산하지 않고 계속 진행하며, 랭킹 점수로 돌아오면 총점을 재확인합니다.
5. 재확인 실패로 중지된 경우 로비에서 현재점수를 다시 읽고 재시작합니다.
