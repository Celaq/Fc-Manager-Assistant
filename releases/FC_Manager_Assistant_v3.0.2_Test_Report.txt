FC 감독모드 도우미 v3.0.2 실행오류 수정 베타
2026-10-18 (한국 시간)

수정 내용
1. 구단주 레벨업 보상 화면의 확인 버튼 인식 추가.
2. 네트워크 오류(연결이 불안정하여 이전 화면으로 돌아갑니다) 본문과
   팝업 구조를 확인한 경우에만 확인 버튼을 눌러 기존 진행 경로로 복귀.
3. 경기 보상 화면의 다음 버튼을 일반 진행/확인보다 우선 처리.
   마우스 올림/눌림에 따른 녹색 밝기 차이를 정규화해 버튼을 비교.
   다른 화면의 인식 허용치를 일괄 높이지 않음.
4. 숫자 3의 실제 점수 글꼴 표본 보완. 새 표본은 8% 이하 차이일 때만
   사용해 숫자 2와 혼동하지 않도록 제한. 기존 숫자 신뢰도 기준 유지.
5. 경기 완료 집계 전과 화면 안정화·재판독 후에 실제 보상 화면인지 재확인.
   로비 화면을 경기 결과로 저장하던 오집계와 잘못된 다음 입력 차단.
6. 스코어 재촬영/판독을 6회에서 최대 12회(약 3초)로 확대.
7. 보상/오류 확인 클릭은 완료 판수를 늘리거나 F8 중지 예약을 소비하지 않음.
   F8은 실제 경기 결과를 집계하고 다음 동작을 실행한 후 적용.
8. 3.0.1의 주차 점수, 등급 승점 제외, 등급 복귀 후 총점 재확인 유지.

검사 결과
- 기존 3.0.1에서 이번 핵심 오류 4건 재현(실패) 후 수정본에서 통과.
- 새 자료 326개 기록: 실제 보상 화면 324장 + 잘못 저장된 로비 2장.
- 기존 미분류 44건 중 숫자 3 관련 42건은 정확한 스코어 판독 통과.
  1장으로 새 글꼴 표본 생성, 나머지 41장은 별도 화면으로 확인.
  남은 2건은 로비로 구분해 결과 집계/다음 버튼 인식에서 제외.
- 기존 판독 성공 282장의 좌우 숫자와 승·무·패가 그대로 유지됨.
- 보상 화면 324장 모두 결과 처리를 일반 확인보다 우선 선택.
- 정체 화면 10장(레벨업 3, 결과 1, 네트워크 오류 6) 모두 다음 동작 인식.
- 재촬영 후 점수 복구, 결과가 로비로 바뀔 때 집계 보류,
  OS 입력을 대체한 실제 입력 분기/F8 예약 처리 검사 통과.
- 이번 검사 670건 + 이전 3.0.1 회귀검사 144건 = 총 814건 통과.
- Windows PowerShell 5.1: C# 컴파일, PowerShell 구문, 전체 WinForms UI 구성,
  자동화가 시작되지 않은 대기 상태와 종료 검사 통과.
- 배포 ZIP CRC 검사 및 소스 일치 확인. 개인 설정/로그/게임 화면은 미포함.

검증 범위
저장된 실제 화면 재생과 상태/입력 분기 검사입니다.
실제 FC 온라인에 키·마우스 입력을 보내는 실게임 테스트는 하지 않았습니다.
네트워크 자체의 원인이나 연결 복구를 해결하는 수정은 아닙니다.
확인 후 게임이 정상 로비/진행 화면으로 돌아온 경우 기존 자동 진행을 사용합니다.
새 종류의 오류, 승급 성공 화면, 다른 해상도/배율은 별도 실게임 확인이 필요합니다.
기존 stats.json의 과거 전적은 자동 보정하지 않습니다. 로비 오집계 2건 때문에
과거 전체 판수가 실제와 다를 수 있으며 이번 수정은 새 오집계를 방지합니다.

사용법
기존 도우미를 종료하고 ZIP을 새 폴더에 압축 해제한 뒤 Start_FC_Manager.cmd 실행.
주차 모드 사용 시 현재점수를 새로 읽고 목표점수를 설정해 주세요.
