FC MANAGER v3.1 · 화면 개편 / N판 진행
2026-10-29 (한국 시간)

변경 내용
- 차콜 배경과 파란색 시작 버튼으로 화면을 개편했습니다.
- 상태 / 시작·중지 / 현재 실행 진행 현황을 상단에 크게 배치했습니다.
- 진행 설정, Discord 알림, 실행 기록을 별도 화면으로 분리했습니다.
- 주차 모드에서도 같은 배색을 유지합니다.
- 판수 제한을 켜고 1~9999판 중 원하는 횟수를 지정할 수 있습니다.
- 기본값은 제한 없음입니다. 숫자 입력 초기값은 20판입니다.
- 이번 시작 이후의 완료 경기만 세며, 과거 실행·전체 누적 판수는 제외합니다.
- 완료 N / 목표 N판, 남은 경기, 진행 막대를 표시합니다.
- 마지막 결과를 저장하고 다음 화면으로 넘긴 뒤 자동으로 멈춥니다.
- 주차 점수 조건이나 판수 조건 중 먼저 충족된 조건으로 중지합니다.
- 달성한 자동 중지는 F8 예약 취소로 해제할 수 없습니다.
- 진행 중 판수 설정은 잠기며, 중지 후 설정을 바꿀 수 있습니다.
- 다시 시작하면 그 시점부터 새로 N판을 셉니다.
- 네트워크 오류·레벨업 확인창은 판수에 포함하지 않습니다.

검사
- 기능 미구현 상태에서 N판 테스트 실패를 확인한 뒤 구현했습니다.
- N판 계산·무제한·재시작·기존 점수 조건 유지 검사 7건 통과.
- 실제 WinForms UI, 설정 잠금/해제, 화면 전환, 실제 결과 등록 함수,
  중복 집계 방지, N=1 및 N판 완료 후 중지 검사 26건 통과.
- 기존 인식/점수/상태 처리 814건 회귀검사 통과.
- 합계 847개 검사 통과. PowerShell 5.1에서 C# 컴파일과 UI 실행 확인.
- 실제 프로그램 화면을 렌더링해 배치와 글자 가독성 확인.
- ZIP CRC/소스 일치 검사, 개인 설정과 게임 캡처 제외 확인.

검증 한계
저장된 실제 게임 화면 및 프로그램 상태·입력 분기 기반 테스트입니다.
테스트 중 실제 게임에 키나 마우스 입력을 보내지 않았습니다.
실제 FC 온라인에서 N판 연속 진행 테스트는 미완료입니다.
새로 제작한 창의 고배율·작은 화면 환경은 별도 확인이 필요합니다.

사용법
1. 기존 프로그램을 종료하고 ZIP을 새 폴더에 압축 해제합니다.
2. Start_FC_Manager.cmd 실행.
3. 진행 설정에서 판수 제한을 체크하고 원하는 숫자를 입력합니다.
4. 일반 모드 또는 주차 모드를 선택합니다. 주차 모드는 시작점수 읽기가 필요합니다.
5. FC ONLINE 창을 선택하고 F9 시작.
6. 완료/남은 경기 표시를 확인합니다. F12 즉시 중지, F8 이번 판까지만 예약.
