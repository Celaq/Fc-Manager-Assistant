FC MANAGER v3.2 · 가독성 / 자동 업데이트 / 추가 오류창
2026-11-11 (한국 시간)

사용법
처음 한 번은 기존 프로그램을 종료하고 3.2 ZIP을 새 폴더에 압축 해제합니다.
Start_FC_Manager.cmd로 실행하면 새 버전을 자동으로 확인합니다.
새 버전이 있으면 변경내용 버튼으로 내용을 확인하고 업데이트 버튼을 누릅니다.
경기 자동 진행 중에는 설치를 시작하지 않습니다. 먼저 자동 진행을 중지하세요.
다운로드와 검증이 끝나면 프로그램이 종료되고 파일 교체 후 다시 실행됩니다.
업데이트 후에는 대기 상태로 시작하며 자동으로 경기를 재개하지 않습니다.
3.1 이하에는 업데이트 기능이 없으므로 이 버전은 수동으로 설치해야 합니다.

화면 개선
- 본문 11.5pt, 숫자 입력 12pt, 주요 상태/진행 수치를 더 크게 표시.
- 비활성 버튼의 글자 대비 개선, 설정 줄 높이와 여백 확대.
- 같은 Windows 기본 한글 글꼴을 사용하므로 추가 글꼴 설치 불필요.
- 창 높이를 늘려 큰 글씨로 인한 겹침을 줄였습니다.

자동 업데이트
- GitHub의 releases/latest.json을 비동기로 읽어 새 버전을 확인합니다.
- 사용자가 버튼을 누른 경우에만 다운로드/설치를 진행합니다.
- 고정 저장소의 HTTPS 주소, ZIP SHA-256, 내부 파일 목록/개별 해시와 버전을 검증합니다.
- 프로그램을 종료한 후 별도 설치 프로세스가 관리 대상 파일만 교체합니다.
- settings.json, stats.json, 진단 로그와 게임 캡처는 교체 대상이 아닙니다.
- 기존 관리 파일을 백업하며, 쓰기 중 실패하면 해당 파일들의 복원을 시도합니다.
- 복원 중 잠긴 파일이 있어도 나머지는 끝까지 복원하며, 복원 실패 시 백업 위치를 알립니다.
- 백업/설치 결과는 프로그램 폴더의 .updates 아래에 보관됩니다.
- 오프라인 확인 실패로 게임 자동 진행이 중지되지 않습니다.
- 업데이트 다운로드/설치 중에는 F9 시작을 차단합니다.

진단 자료 반영
- 3.1이 처리하지 못한 게임 오류/알림 문구와 네트워크 오류 문구를 추가했습니다.
- 제공된 추가 오류창 59장을 정확한 문구/팝업 구조/버튼 조합으로 인식했습니다.
- 숫자 6 때문에 미분류였던 스코어 3:6, 6:1, 1:6 판독을 보완했습니다.
  기존 숫자 판독 기준은 완화하지 않고 실제 글자 모양 표본만 추가했습니다.
- 하이라이트/후반 종료 안내의 짧은 반복으로 15초 만에 멈춤 알림을 보내던 것을
  기존 S 안내처럼 3분 이상 화면 변화가 없는지 확인하도록 맞췄습니다.
- 매칭 대기 및 검은 화면에는 임의 키나 클릭을 보내지 않습니다.
- 이 수정은 게임 서버/네트워크 장애 자체를 해결하는 기능은 아닙니다.

검증
- 기존 인식·점수·상태 회귀검사 814건 통과.
- 판수 제한 검사 7건, UI/시작·중지/업데이트 상태 검사 33건 통과.
- 실제 ZIP 설치, 해시 거부, 경로 이탈 거부, 설정/전적 보존,
  실제 쓰기 중 실패 후 복구, 별도 설치 프로세스와 재실행 검사 통과.
- 새 진단 점수 화면 946장 검사: 기존 943장 좌우 숫자 유지, 미분류 3장 해결.
- 추가 오류창 59장 인식 통과. 나머지 화면 4장은 개별 확인했습니다.
- Windows PowerShell 5.1에서 컴파일/구문/실제 UI 렌더링 확인.
- 최종 배포 ZIP의 CRC와 파일별 해시, 설치 결과 일치 여부를 확인합니다.

검증 한계
실제 게임에 키/마우스를 보내는 연속 경기 테스트는 하지 않았습니다.
별도 설치 프로세스 검사는 테스트 전용 실행기로 재실행 여부를 확인했습니다.
실제 다음 버전의 온라인 설치는 그 버전이 배포된 후 별도 확인이 필요합니다.
백신 탐지 여부와 모든 Windows 배율/테마 조합은 보증하지 않습니다.
폰트/오류 수정은 과거 저장 전적을 자동 보정하지 않습니다.
